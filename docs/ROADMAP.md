# Forumo Delivery Roadmap

This document tracks the staged rollout defined in the project brief. Each stage builds on the last, ensuring backend, frontend, and operations readiness before moving forward.

1. **Foundations (current stage)** – Monorepo bootstrapping, API skeleton with Auth/Users/Health modules, React web shell, CI, and Docker Compose.
2. **Authentication MVP** – Email-based login, refresh tokens, and guarded routes.
3. **User Profiles & KYC** – Profile editing, mock KYC flows, and file uploads.
4. **Catalog** – Listings, categories, and basic search.
5. **Escrow Orders** – Offer-first checkout backed by Stripe Connect.

Subsequent phases cover messaging, reviews, admin tooling, auctions, advanced fulfillment, and mobile.
